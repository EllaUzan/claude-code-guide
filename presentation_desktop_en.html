The home Claude works inside
Claude only sees what's in the folder you chose.
It doesn't leave. It doesn't search. It doesn't peek sideways.

Which means everything inside — it sees.
What should NOT be there:
Passwords and .env files · Sensitive personal data · Disk backups and system folders
💡 Recommendation: a clean practice folder before touching real projects. A space where mistakes have no consequences.

A few rules nobody told you
01 Write in your own language
No need to write in formal English to sound professional. Be direct. It understands you either way.
02 "Update the site" — that's not a task
That's a wish. Be specific: what, where, in which direction. The clearer the task, the less it improvises.
03 Tell it why
"Because I want this to look more professional" — that's information. It works differently when it understands the goal. Unlike contractors.
04 It made a mistake? Say so. Directly.
It won't be offended. It won't sulk. It won't send a passive-aggressive message three hours later. It will fix it.
05 Ask "what did you change?"
After a big action — a perfectly legitimate question. It will tell you exactly. You don't need to guess and feel lost.
06 Don't swallow the elephant whole
"Build me a website" is not a task, it's an entire project. "Add a contact button to the homepage" — that's a task.
Your First Assignment
Ask Claude to build you a simple weekly HTML page.
Yes — a real page you can open in a browser and feel like a proper digital human for a moment.

The idea is not to complicate things. It's to see how quickly a few lines of text can become something visual, organized, and beautiful.

You simply give it a title, a few tasks for the week, maybe a small note at the bottom — and it builds you a neat little page.

A perfect starting assignment: simple, satisfying, and it immediately shows you that Claude doesn't just "talk" — it actually creates something with you that you can see.
The full prompt — on the next slide →
The Prompt — copy and adapt
Hey Claude, this is my first time with Claude Code and I'm just getting started. I'd like you to create a simple, clean, and pleasant HTML page that displays my weekly plan. It's important to me that it's clear, organized, and has a nice but not overly complex design. Use the following content: Title: [write your title here] Subtitle: [write your subtitle here] Visual style: [minimalist / colorful / dreamy / elegant / playful] (You can also describe freely — "something with flowers", "ocean blue", "like a beautiful newsletter") My tasks for the week: - [task 1] - [task 2] - [task 3] - [task 4] - [task 5] A small note at the bottom: [write a note if you'd like] Please: - Create everything in a single HTML file - Add simple CSS inside the same file - Keep the design beautiful, clear and user-friendly - Save the file as week.html - After creating it, explain in plain words what you made - Tell me exactly how to open the file in a browser Assume I know absolutely no code.
