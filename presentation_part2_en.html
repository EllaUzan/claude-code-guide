Tool #1 — The one worth knowing
The Terminal:
a black screen that somehow got a terrifying reputation.
The Terminal is simply a window where you type instructions to your computer. That's genuinely the whole story.
No buttons, no menus, no reassuring icon saying "click here, everything will be fine".

Yes, it looks like something from a hacking film. Black screen, cryptic text, the vague sense that someone's about to say "we've got thirty seconds before the firewall kicks in".
In reality, it's far less cinematic than that. It's simply a place where you tell the computer what to do, directly.

Claude Code works beautifully there — it's essentially its natural habitat.
You don't have to love it.
Just understand it's less "dangerous hacker" and more "window without a GUI."

Tool #2 — Entirely optional
VS Code: powerful, clever, and perhaps a touch much for a first date.
VS Code is a professional code editor — designed for people who want to work with code with more control, more tools, more structure.
And, let's be honest, significantly more things on screen at once.
If the Terminal feels like speaking directly to your computer, VS Code feels like stepping into a control room.
There are panels, sidebars, tabs, colours, extensions, and a brief moment where you think:
"Am I working, or am I piloting something?"
Think of it as the move from iMovie to Premiere. Not because it's the same thing — but because suddenly there's considerably more power at your disposal, and also a slightly higher chance of sitting in front of it for two minutes pretending you know exactly what you're doing.
It's an excellent tool.
You simply don't need to start at the "we're still getting to know each other" stage.
This chapter will be here when you're ready.

Whichever one doesn't make you close the laptop.

First step in VS Code
The first thing you do:
open a folder.
You don't need to understand all of VS Code to get started.
You just need to open your project folder.

That folder tells Claude:
this is your territory. We work in here.

It can only see what's inside,
and it only works there.
Not on your desktop, not in other folders,
and not in anything you didn't intend it to touch.
In short, the folder is how you tell Claude:
yes here. not there. thank you very much.
